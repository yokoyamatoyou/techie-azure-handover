# 人間らしさアルゴリズムの評価：AIっぽさを消し、人間味を出せるか

本ドキュメントは、現在の Human Resonance パイプラインが「AIっぽさを無くし、人間味のある文章を生成できるか」を、想像力を働かせて評価したものです。

---

## 1. 現状で「できること」

| 観点 | 内容 |
|------|------|
| **一貫した人格** | Phase 0 で一人称・口癖を固定し、「誰が書いているか」を明確にする。 |
| **共感の手がかり** | Phase 1 で既存文の並べ替えにより、脆弱性・感情の言語化・呼びかけを前面に出す。 |
| **単調さの緩和** | Phase 4・5 で文長の揺らぎ、接続詞・文末・言い回しの反復を抑え、テンプレ感を減らす。 |
| **人間味マーカーの追加** | Phase 3 で言い直し・曖昧さ・カジュアル・脱線を「既存文の挿入」で補う。 |
| **法務・品質** | Phase 6・7 でリスク表現の除去、禁止フレーズ・句読点の正規化を行う。 |

これらにより、**無処理のLLM出力よりは「整っていて、少し人間っぽい」文章**にはなる。

---

## 2. 限界：なぜ「完全に人間」には届きにくいか

### 2.1 土台がまだLLMである

- パイプラインの**入力はすでにLLMが生成したドラフト**である。
- 話題の選び方、論の進め方、比喩の好み、情報の密度は、すべてドラフト時点で決まっている。
- 後段で「マーカーを足す」「並べ替える」「言い回しを変える」だけでは、**誰か一人の書き手の「思考の流れ」や「文体の核」**は変えられない。
- 結果として、「人間味の付け足し」が乗ったLLM文体になりがちである。

### 2.2 「人間味」がパターン化している

- Phase 1・3 では「共感マーカー」「人間味マーカー」の**出現有無**でスコアを出し、足りないと既存文の移動や挿入で補う。
- 使う表現は `EMPATHY_MARKERS` / `HUMANITY_MARKERS` の**固定リスト**（「正直」「ちなみに」「なんですよね」など）に依存している。
- 記事が増えるほど、**同じマーカーが同じような文脈で繰り返し**出てきやすく、「AIが人間っぽく見せようとしている型」と読者に感じさせるリスクがある。
- 本当の人間らしさは「この人ならではの言い回し」や「一貫した癖」であり、**辞書的なマーカー一覧では再現しきれない**。

### 2.3 一貫しすぎて「不自然にきれい」になる可能性

- Phase 5 では一人称の統一、文体の統一、反復の削減を行う。
- 人間の実際の文章には、**意図的な繰り返し**、**少しの揺れ**、**途中でトーンが変わること**がある。
- アルゴリズムが「揺らぎを抑えめに」「1段落1回まで」と制御する一方で、**過度に整えすぎると、かえって無機質で整いすぎた印象**になる可能性がある。
- 「完璧に校正された記事」と「人間が書いた少し雑な記事」の差は、**あえて残す不揃いさ**にある。

### 2.4 感情の「流れ」は制御していない

- 共感・興味・人間味は**局所的なマーカー**で評価・付与している。
- しかし人間の記事には**冒頭の不安 → 中盤の気づき → 締めの安心**のような**感情のアーク（弧）**がある。
- 現在のパイプラインは「どこにどんな感情を置くか」の**全体設計**は持っておらず、ドラフトの流れに依存している。
- そのため、**論理は整っていても、感情の起伏が平坦**なままになることがある。

### 2.5 「誰」の人間味かが弱い

- Phase 0 で一人称と口癖は決めるが、**文の長さの好み・接続詞の好み・比喩の傾向・段落の長さ**など、書き手ごとの**文体（イドイオレクト）**は定義していない。
- 同じパイプラインで処理すると、**記事ごとにマーカーや揺らぎのパターンが似て**、「一人の人間」というより「同じAIが人間モードで書いた複数記事」に見えやすい。
- 本当の人間味は「この著者ならではの一貫した癖」であり、**ペルソナを「一人称＋口癖」だけでなく「文体プロファイル」まで広げないと、差別化は難しい**。

### 2.6 人間らしさの「結果」を測っていない

- 各 Phase は**スコア（マーカー数・文長分散など）**で発動条件を決めている。
- 「読んだ人がどれだけ人間が書いたと感じるか」という**出力側の評価**はしていない。
- そのため、**マーカーや揺らぎは増えても、主観的な「人間味」は必ずしも増えない**という乖離が起きうる。

---

## 3. 総合判断

- **「AIっぽさを減らす」**という点では、**ある程度は達成している**。  
  反復の抑制、禁止フレーズ・句読点の整理、共感・人間味マーカーの付与により、無処理のLLM出力よりは読みやすく、整った印象になる。
- **「人間味のある文章を生成できるか」**という点では、**条件付きでイエス**である。  
  - 人間味の**手がかり**（共感・曖昧さ・リズムの揺らぎ）は増やせる。  
  - 一方で、**土台がLLM**であり、**人間味がパターン化**しており、**感情の流れや「一人の書き手」らしさ**は弱い。  
  - そのため、「人間が書いたと錯覚するほど自然」かどうかは、**ドラフトの質と、読者の許容度**にかなり依存する。

---

## 4. 今後の検討の方向（想像の範囲）

アルゴリズムを「さらに人間らしく」するために、検討の余地がある方向を挙げる。

| 方向 | 内容 |
|------|------|
| **文体プロファイル** | 一人称・口癖に加え、「短文多め／長文多め」「接続詞の好み」「段落の長さ」などをプロファイル化し、Phase 4・5 の閾値や置換候補を変える。 |
| **感情アークの設計** | 記事の「導入・展開・結び」に対応する感情目標（不安→期待→安心など）を設定し、Phase 1・2 の適用位置や強さを変える。 |
| **マーカーの多様化** | 固定リストに依存しすぎないよう、ペルソナごとの「好みの言い回し」リストを持ち、ランダムに選ぶか、使用履歴で重複を避ける。 |
| **意図的な不揃いの許容** | 反復削減や言い換えに「例外」を設け、特定のキーワードやリズムは意図的に繰り返す、または揺らぎの上限を緩める。 |
| **人間らしさの評価** | 出力を「人間が書いたか／AIが書いたか」で評価する簡易モデルやルーブリックを用意し、パイプラインのパラメータや発動条件のチューニングに使う。 |

---

## 5. まとめ

- 現状のアルゴリズムは、**AIっぽさを抑え、人間味の手がかりを足す**ことで、**無処理よりは人間に近い文章**を出せる。
- ただし、**土台がLLM**であること、**人間味が辞書的・パターン的**であること、**感情の流れや「一人の書き手」らしさ**が弱いことから、**「完全に人間が書いたような文章」**を保証するまでには至っていない。
- 上記の限界を意識しつつ、**文体プロファイル・感情アーク・マーカー多様化・意図的な不揃い・人間らしさ評価**などを検討すると、さらに人間味を増やせる余地がある。
