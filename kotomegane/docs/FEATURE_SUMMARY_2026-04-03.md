# Feature Summary 2026-04-03

この文書は `kotomegane` の現行機能を短時間で把握するための要約です。  
実装の正本は `AGENTS.md`、現在値の正本は `docs/CURRENT_STATE_2026-03-30.md` を参照します。  
ここでは、ユーザー目線で見える機能と画面導線を優先して整理します。

## 1. 何ができるか

`コトメガネ` は、入力した質問で

- 自社URLが AI の回答や引用に出るか
- ブランド名がどれくらい出るか
- 競合や外部サイトがどこで強いか
- 次にどのページを直すべきか

を確認するための可視化 PoC です。

## 2. 主要導線

### 2.1 その場で確認する

- `質問`
- `自社URL`
- `ブランド名`

を入れて `分析を実行` すると、主結果 3 カードと詳細分析が出ます。  
`質問 / 自社URL / ブランド名` は必須です。

### 2.2 入力内容を保存して再利用する

画面上では `確認内容` という名前で保存します。  
これは、質問・自社URL・ブランド名・競合語などの入力一式を再利用するための保存単位です。  
内部実装では `question_set` ですが、ユーザー向け UI では `確認内容` として扱います。

### 2.3 定期チェックする

保存した `確認内容` を使って、

- 曜日
- 時刻
- 週あたり回数

を設定すると、定期的に自動実行できます。  
日時は `この時刻から処理を開始する` 意味で、結果反映には最大 24 時間かかる場合があります。

### 2.4 まとめて確認する

通常実行とは別に `まとめて確認` があり、OpenAI Batch API を使って一括実行できます。  
結果は通常実行と同じ履歴・カード・詳細に入ります。

## 3. 主結果で見えること

- `自社が出たか`
- `外部名・外部サイト`
- `次に見直す質問`

の 3 カードを最初に見せる構成です。  
結果カードでは、難しい内部情報よりも、今の見え方と次の改善判断を優先して表示します。

## 4. 詳細で見えること

`詳細を見る` の中では、主に次を確認できます。

- ダッシュボード概要
- AI visibility スコア推移
- 自社露出率 / 外部サイト優勢率の推移
- 意図マップ
- 不足ページナビ
- 質問別の推移
- 根拠URL
- 実行履歴
- 出力ファイル

## 5. 現在の分析機能

### 5.1 長文短文化

- 日本語 50 文字超の長文質問は、内部で短く整えて実行します
- UI には元質問をそのまま残します
- 地域、価格条件、対象読者、比較軸などは落とさない方針です

### 5.2 拡張検索

- 1つの元質問を、内部で最大 5 件の関連質問に広げて確認します
- 比較、料金、FAQ、事例などを軸にします
- 不自然な 4 軸固定にはしません

### 5.3 前回比サマリ

- 同じ条件で再実行したときだけ前回比を出します
- 比較指標は `自社露出率 / 平均 visibility スコア / 外部サイト優勢率`
- 条件が変わった場合は、前回比を無理に出しません

## 6. 保存される主な情報

- 実行履歴
- 回答本文
- 引用URL
- query plan
- 内部で使った質問
- 自社 / 競合 / 外部の判定材料
- export 用データ

## 9. 用語

- `確認内容`
  - ユーザー向け UI での呼び方
  - 入力一式を保存して再利用する単位
- `定期チェック`

  - Batch API を使った一括実行
- `前回比サマリ`
  - 同条件の直近 2 run を比べる簡易比較
